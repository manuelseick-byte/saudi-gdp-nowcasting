# Code availability

The MATLAB implementation used in this project builds on code supplied as course material for the Nowcasting & Forecasting course.

To respect the provenance of those materials, the MATLAB source files are not redistributed publicly in this repository.

The repository instead documents the research question, data sources, modelling approach, and results through the project paper and accompanying documentation.

This repository should therefore be viewed as a project portfolio page rather than an independent replication package.
